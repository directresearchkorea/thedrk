# 일본 B2B 타겟 한국 시장 조사 서비스 노출 극대화 전략 (포트폴리오 단일 페이지 최적화)

기존 사이트 전체를 다국어화하는 대신, **포트폴리오 메뉴 내에 고품질의 일본어 전용 단일 소개서 페이지**를 구축하여 비용을 최소화하고 검색 엔진 및 AI 크롤러의 도달률을 극대화하는 실용적인 전략으로 변경합니다.

## User Review Required

> [!IMPORTANT]
> **단일 페이지 집중 전략의 핵심 방향성**
> 1. **URL 설계**: 포트폴리오 메뉴 하위에 일본인 검색어가 포함된 URL을 생성합니다. (예: `/portfolio/korean-market-research-ja` 또는 `/portfolio/korea-market-research-service-japanese`)
> 2. **크롤링 경로(Crawl Path) 확보**: 기존 영어 메인 페이지와 포트폴리오 목록 페이지에서 이 일본어 단일 페이지로 이어지는 텍스트 링크(Anchor Link)를 명확히 배치하여 검색 로봇이 쉽게 발견하게 합니다.
> 3. **원스톱 레이아웃**: 페이지 하나에서 [서비스 정의 ➔ 방법론 ➔ 4대 특화 분야 실적(게임/화장품/식품/로봇) ➔ 문의 폼]까지 완결되는 긴 호흡의 정보성 랜딩 페이지로 설계하여 이탈률을 낮추고 체류 시간을 늘립니다. (SEO 지수 향상 핵심 요인)

## Proposed Changes

### 1. 단일 일본어 페이지 구조 및 온페이지 SEO 설계
일본인 유저와 검색 로봇이 동시에 만족할 수 있는 페이지 구조를 설계합니다.

*   **타겟 URL 경로**: `https://yourdomain.com/portfolio/korea-market-research-service-japanese`
*   **페이지 구성 요소 (위에서 아래로)**:
    1.  **헤드라인**: "한국 현지 직접 대응 B2B 전문 시장조사 서비스"
    2.  **우리 회사의 강점 (USP)**: 현지 네트워크 보유, 신속한 한국 규제 분석, 정성/정량 통합 리서치 가능성
    3.  **조사 방법론**: 데스크 리서치부터 FGI, 현장 미스터리 쇼핑까지 원스톱 지원 설명
    4.  **산업별 실제 사례 (Case Studies - 핵심 영역)**:
        *   *게임*: 한국 모바일/PC 게임 시장 동향 및 유저 성향 리포트 경험
        *   *화장품*: K-뷰티 트렌드 분석 및 오프라인 H&B 스토어 유통망 실태 조사
        *   *식품*: 푸드/F&B 트렌드 및 현지 소비자 선호도 조사
        *   *쿠킹 로봇*: 한국 요식업계의 서비스/조리 로봇 도입 실태 및 규제 분석
    5.  **문의 양식 (Contact Form)**: 일본 기업 담당자가 바로 문의할 수 있는 간이 폼 배치

---

### 2. 크롤링(Crawling) & 인덱싱(Indexing) 극대화 기술 전략
단 하나의 페이지만 등록하기 때문에 검색 로봇이 이 페이지를 신속하게 수집하고 신뢰하도록 만들어야 합니다.

```mermaid
graph TD
    A[영어 메인 페이지 & 영어 포트폴리오 목록] -->|Anchor Link: '日本語の紹介はこちら'| B(일본어 단일 소개 페이지)
    B -->|Sitemap.xml 추가| C(Google Search Console / Bing Webmaster Tools)
    B -->|JSON-LD 구조화 데이터 삽입| D(AI 엔진 크롤러: ChatGPT/Gemini)
    C -->|수집 및 색인| E[구글 & 야후 1페이지 노출]
    D -->|인용 데이터 수집| F[AI 검색 결과 답변 노출]
```

*   **내부 링크 구조 (Internal Linking)**: 영어 메인 페이지의 헤더/푸터 또는 포트폴리오 목록 페이지 상단에 **"日本語での韓国市場調査サービス紹介はこちら" (일본어 한국시장조사 서비스 소개는 여기로)** 와 같은 텍스트 링크를 명확히 걸어 검색 로봇의 크롤링을 유도합니다.
*   **Sitemap.xml 업데이트**: 새로 생성된 단일 일본어 페이지 URL을 사이트맵 파일에 수동으로 등록하고 Google Search Console에 재제출합니다.
*   **Hreflang 태그 미적용**: 사이트 전체의 1:1 다국어 매핑이 아니기 때문에, hreflang 대신 단일 페이지로서의 완결성을 갖추도록 HTML 메타 데이터를 작성합니다.

### 3. AI 검색 추천(GEO) 최적화: 마크업 및 콘텐츠 레이아웃
단일 페이지 안에서 AI가 정보를 쉽게 추출하도록 정문화된 구조를 사용합니다.

*   **스키마 마크업 (JSON-LD)**:
    이 단일 페이지의 HTML 헤더 내에 아래와 같은 구조화 데이터를 삽입하여 AI가 본 페이지를 `Project` 또는 `Service` 형태로 완벽하게 인지하도록 돕습니다.
    ```json
    {
      "@context": "https://schema.org",
      "@type": "Service",
      "name": "韓国市場調査代行サービス (한국 시장조사 대행 서비스)",
      "provider": {
        "@type": "Organization",
        "name": "귀사명",
        "url": "https://yourdomain.com"
      },
      "areaServed": "JP",
      "offers": {
        "@type": "Offer",
        "description": "韓国のゲーム、化粧品、食品、調理ロボット市場に関する専門リサーチサービス"
      }
    }
    ```
*   **가독성 높은 텍스트 태그**: 핵심 조사 실적 카테고리(게임, 화장품, 식품, 로봇)에 `<h2>` 또는 `<h3>` 태그를 적용하고, 주요 수행 프로젝트를 표(Table)나 불릿포인트 리스트 형식으로 깔끔하게 정리하여 AI의 요약 크롤링 효율을 높입니다.

## Verification Plan

### 1단계: 온페이지 SEO & 스키마 기술 검증
*   해당 포트폴리오 페이지 개설 후 Google Rich Results Test를 통해 구조화 데이터(JSON-LD) 파싱 결과 검증.
*   일본어 텍스트 내 키워드 밀도(Keyword Density)와 가독성 검토.

### 2단계: 검색 및 AI 답변 노출 추적
*   구글 서치콘솔의 'URL 검사' 기능을 통해 강제 색인(Indexing) 요청 진행 후, 색인 완료 여부 모니터링.
*   실제 일본 구글/야후 및 ChatGPT, Gemini에서 `"韓国 ロボット市場調査 会社"`, `"韓国 ゲーム市場 トレンド 調査 代行"` 등의 질문을 입력하여 노출 여부 주기적 테스트.
